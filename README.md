# Portfolio — Joaquín Trujillo

Portfolio personal de una sola página desarrollado con Astro, TypeScript y Tailwind CSS.

## Ejecutar en local

```bash
npm install
npm run dev
```

Abrir `http://localhost:4321`.

## Editar contenido

- Información personal y enlaces: `src/data/personal.ts`
- Tecnologías: `src/data/skills.ts`
- Proyectos: `src/data/projects.ts`
- Experiencia y formación: `src/data/experience.ts`

```bash
npm run build
```
